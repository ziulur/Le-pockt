# LE Pocket

Emulador de Game Boy, Game Boy Color, Game Boy Advance e Nintendo DS (etapa 1), da LE Games.

- **Android:** baixe `LE-Pocket.apk` em [Releases](../../releases/latest).
- **iPhone:** `LE-Pocket.ipa` (sem assinatura) em [Releases](../../releases/latest), ou abra https://ziulur.github.io/Le-pockt/ no Safari e use "Adicionar à Tela de Início".
- **Windows:** `LE-Pocket-Windows.zip` em [Releases](../../releases/latest). **Navegador:** `LE-Pocket.html`.

Os jogos não vêm incluídos.

Código-fonte em `src/`, testes em `tests/`, montagem em `tools/build.py`. Veja [docs/BUILD.md](docs/BUILD.md).

Arquivos gerados (não edite à mão): `index.html`, `sw.js`, `manifest.webmanifest`, ícones da raiz e `web/index.html`.
