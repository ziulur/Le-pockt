# LE Pocket

Emulador de Game Boy, Game Boy Color, Game Boy Advance e Nintendo DS (etapa 1), da LE Games.

- **Android:** baixe `LE-Pocket.apk` em [Releases](../../releases/latest).
- **iPhone:** `LE-Pocket.ipa` (sem assinatura) em [Releases](../../releases/latest), ou abra a versão web no Safari e use "Adicionar à Tela de Início".
- **Windows / navegador:** `LE-Pocket.html`.

Os jogos não vêm incluídos.

Pastas: `web/` (emulador em um arquivo), `docs/` (versão web instalável), `android/` e `ios/` (aplicativos que embutem o emulador).
